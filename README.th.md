> [!WARNING]
> dekpop เป็นซอฟต์แวร์วิจัยสำหรับจัดการอุปกรณ์ของคุณเอง ควรสำรองข้อมูลก่อนใช้งาน และใช้เฉพาะกับอุปกรณ์และข้อมูลที่คุณเป็นเจ้าของ เพราะแอปสามารถแก้ไขไฟล์ภายในคอนเทนเนอร์ของแอปได้

## มีอะไรใหม่ใน 4.0.1 — การ์ดประกาศที่ดูเป็นทางการ

> การ์ดเดิม หน้าตาใหม่ให้เป็นทางการขึ้น และไม่กินสเปคเลยตอนแสดง

- **การ์ดเป็นทางการ** — ส่วนหัวเป็นไล่สีแบรนด์พร้อมโลโก้ dekpop เวอร์ชันของรุ่น และปุ่มปิดปุ่มเดียว ตามด้วยป้ายหัวข้อ ชื่อเรื่อง เนื้อหา และปุ่มหลักที่ชัดเจนเพียงปุ่มเดียว
- **ไม่มีต้นทุนจากรูป** — ลบภาพแบนเนอร์ JPEG ขนาด 1 MB และ imageset ออกหมดแล้ว ไม่ต้องถอดรหัสรูปตอนเปิด การ์ดจึงขึ้นทันทีแม้บนเครื่องที่หน่วยความจำเหลือน้อย
- **แอนิเมชันสั้นลง** — เข้า/ออกใช้เฟด 0.18 วินาทีพร้อมสเกล 0.97 รองรับ Reduce Motion การ์ดมีเงาเล็กหนึ่งชั้น ไม่มีเบลอ และไม่มีการเคลื่อนไหววนซ้ำ
- เวอร์ชันปัจจุบัน `4.0.1` (build 35)

## มีอะไรใหม่ใน 4.0.0 — เอา exploit ออก เบาและลื่น

> ระบบ kernel exploit ถูกนำออกทั้งหมดแล้ว ไม่มีอาการค้างตอนเปิด ไม่มี watchdog และเครื่องไม่รีสตาร์ท

- **ลบ exploit ทั้งชุด** — `kexploit/`, `KernelExploit.swift`, แบนเนอร์สถานะ exploit, หน้าขออนุญาต และการรันตอนเปิดแอป ถูกลบออกหมด การเข้าถึงโฟลเดอร์ที่อ่านได้ใช้เฉพาะชั้นที่ปลอดภัย ได้แก่ อ่านโดยตรง, เปิดใช้งาน MCM container, traversal grant และการเดิน inode
- **ลบของแอบแฝง** — ลิงก์ attribution ที่ถูกเข้ารหัสไว้, การเรียก attestation ปลอมใน `AppInfo` และท่าทางซ่อนในหน้าต่าง รวมถึงการ override `fork()` เพื่อหลบการตรวจ jailbreak ถูกลบออก
- **เปิดแอปไม่สะดุด** — คิวสแกนเดียวแบบอนุกรม, แคช metadata และ LaunchServices 10 นาที, แสดงรายการแรกก่อนเดินไฟล์ซิสเต็ม, อัปเดตความคืบหน้าไม่เกินทุก 0.5 วินาที
- **UI พอดีจอ** — แถบเครื่องมือหน้าไฟล์เป็นไอคอนล้วน แถบเลือก/วางจำกัดข้อความ ป้ายแท็บจำกัดความกว้าง และทุกอย่างอยู่ในระยะขอบที่ปรับตามจอ
- **ไฟล์เล็กลง** — ลบโค้ด patch, cleaner, wallpaper, onboarding, settings และชุดไฟล์ประมาณ 40 ไฟล์ บันทึกในแอปถูกจำกัดที่ 800 บรรทัด
- เวอร์ชันปัจจุบัน `4.0.0` (build 34)

## มีอะไรใหม่ใน 3.0.0 — เบาขึ้น เร็วขึ้น ลื่นขึ้น

> ออกแบบใหม่ทั้งหมดสำหรับ iPhone รุ่นเก่า: ไม่มีอาการค้าง ไม่มี UI ล้นออกนอกจอ และไม่มีฟีเจอร์ชุดไฟล์ที่ไม่ได้ใช้อีกต่อไป

- **พื้นหลังแบบนิ่ง** — ทั้งแอปใช้สีพื้นเดียวและไล่สีแบบนิ่ง ไม่มี Canvas ออโรร่า 30 fps, อนุภาค 28 จุด, mesh เบลอ 4 ชั้นที่เคลื่อนไหว หรือพื้นหลังเบลอชั้นที่สามในลิสต์อีกต่อไป และไม่มี `repeatForever`, `plusLighter` หรือ `.ultraThinMaterial` บนหน้าจอที่ใช้งานจริง
- **UI พอดีจอ** — ตัวเลือกหมวดในหน้า Files เป็นคอนโทรลแบบแบ่งความกว้างเท่ากันที่ล้นจอไม่ได้ ช่องค้นหาเป็นแคปซูลเบา ลิสต์และหน้าจอรองถูกจำกัดความกว้างที่ 760 pt และจัดกึ่งกลาง พร้อมระยะขอบที่ปรับตามความกว้างจอ จึงไม่มีอะไรไปอยู่ใต้ขอบขวาบน iPhone SE
- **แถบเครื่องมือเรียบง่าย** — รวมปุ่มภาษา ธีม และคำสั่งโฟลเดอร์ 4 รายการไว้ในเมนูตัวเลือกเดียว ปุ่มแท็บ และเมนูเพิ่มเติมอีกหนึ่งเมนู ทำให้แถบนำทางมีที่ให้ชื่อหน้าจอ
- **ลิสต์เร็วขึ้น** — แถวไฟล์สูง 52 pt ระยะขอบแน่นขึ้น และไอคอนแอปโหลดผ่านคิวเดียวแบบอนุกรม ไม่ใช่หนึ่งงานต่อหนึ่งแถว
- **ค้นหาแอปเร็วขึ้น** — การค้นหาคอนเทนเนอร์แบบค่อยเป็นค่อยไปอัปเดตหน้าจอไม่เกินหนึ่งครั้งต่อ 24 แอปใหม่ แทนการรวมและเรียงลำดับทั้งรายการทุกครั้งที่มีความคืบหน้า
- **เปิดแอปเร็วขึ้น** — kernel exploit เริ่มหลังเฟรมแรก 0.8 วินาทีที่ QoS `.utility` การสแกนครั้งแรกและเฟรมแรกจึงไม่ถูกบล็อก หน้าเปิดแอปเป็นภาพนิ่งพร้อมเฟดเข้าครั้งเดียว และประกาศแสดงเพียงครั้งเดียวต่อประกาศ ไม่ใช่ทุกครั้งที่เปิดแอป
- **นำ Asset Sets ออกแล้ว** — ลบโมเดล service และหน้าจอทั้ง 5 หน้าออก แต่ทางลัดโฟลเดอร์ที่บันทึกไว้ยังใช้ได้และย้ายไป `ShortcutStore` ใหม่อัตโนมัติ
- เวอร์ชันปัจจุบัน `3.0.0` (build 30) ตารางข้อความอังกฤษ/ไทยยังมีคีย์ครบเท่ากัน

## อัปเดต 3.0.2 - เห็นผลของ exploit ชัดเจนขึ้น

> เปิด exploit แล้วจะไม่เจอรายการว่างแบบไม่มีคำอธิบายอีก

- **บอกสาเหตุจริง** - แถวสถานะแสดงขั้นที่หยุด (kernel primitive, `proc_self`, offset ไม่ตรง หรือ layout ของ sandbox escape) แทนเลข `-1` คงที่
- **แบนเนอร์ในหน้า Files** - ถ้าล้มเหลวจะเห็นแบนเนอร์สีแดงพร้อมรายละเอียด ปุ่มลองใหม่ และปุ่มคัดลอกข้อมูลวินิจฉัยในแตะเดียว ถ้าได้ kernel R/W แต่ sandbox escape ไม่ผ่านจะเป็นสีส้ม
- **รายการรีเฟรชเอง** - เมื่อ exploit จบ แอปจะโหลดรายการแอปใหม่และล้างแคชโฟลเดอร์ว่าง ทำให้เห็นผลทันทีโดยไม่ต้องปิดแอป
- **แก้การตรวจที่เปราะเกินไป** - การตรวจก่อน escape รับ `proc.p_pid` เพิ่มจาก `proc.p_name` ทำให้ offset ที่ถูกต้องไม่ถูกยกเลิกเพียงเพราะฟิลด์ชื่อย้ายที่
- เวอร์ชันใหม่คือ `3.0.2` (build 32)

## อัปเดต 3.0.1 - วินิจฉัย iOS 27 และกันเครื่องพัง

> การเข้าถึงไฟล์ลึกต้องมี exploit ที่ใช้ได้ บน iOS 27 ขึ้นไป แอปจะหยุดก่อนที่จะไปเขียน kernel ผิดที่

- **ช่วงที่ exploit ตรวจสอบแล้ว** - `kexploit/offsets.m` ตรวจสอบถึง iOS 26.x เท่านั้น เวอร์ชันใหม่กว่าจะไม่รัน exploit อัตโนมัติ แต่ Files ยังลองอ่านตรง, MCM, traversal grant และ inode walk ตามปกติ
- **เปิดใช้เองพร้อมคำเตือน** - แบนเนอร์สีส้มในหน้า Files และสวิตช์ใน Settings ให้คุณรัน exploit ที่ยังไม่ยืนยันได้เอง หลังยืนยันแล้วว่าจะรับความเสี่ยงเครื่องรีสตาร์ท
- **ตรวจ offset ก่อนแก้ sandbox** - หลังได้ kernel R/W แอปจะอ่านชื่อโปรเซสของตัวเองจาก kernel ถ้าไม่ตรงกับ `dekpop` จะข้าม sandbox escape แทนที่จะไปเขียนหน่วยความจำอื่น
- **วินิจฉัยละเอียดขึ้น** - หน้ารายงานความเข้ากันได้แสดงขั้นสุดท้ายของ exploit และตารางลอง traversal grant (depth 6-12 x 2 คลาส) ถ้า Apple ปิด จะเห็นเป็น "ถูกปฏิเสธทุก variant"
- เวอร์ชันใหม่คือ `3.0.1` (build 31)

## มีอะไรใหม่ใน 2.1.0 — รองรับ 27.0.1 + โฟลเดอร์ที่เปิดได้เสมอ

> **iOS 27.0.1 ได้รับการยอมรับชัดเจนแล้ว** และ Files ใช้งานได้จริงแม้เข้าคอนเทนเนอร์แอปไม่ได้

- **ไม่มีเงื่อนไขเวอร์ชันอีกต่อไป** — `ExploitSupportPolicy.accepts(version:build:)` เป็นประตูตรวจสอบเพียงจุดเดียวและไม่สนค่าทั้งสองตัว ดังนั้น `27.0.1`, บิลด์เบต้า และเวอร์ชันในอนาคตถูกรับรองเหมือน `16.0` ทุกประการ การ์ดหน้า Files แสดง **"iOS 27.0.1 · รองรับ"** และหน้าเปิดแอปไม่สามารถแสดงข้อความ "ยังไม่รองรับ" ได้อีก
- **ทำไมยังดูเหมือนไม่รองรับ:** บน iOS 27.0.1 ยังไม่มี kernel offsets ที่ตรงกับเคอร์เนล ช่องโหว่เสริมจึงใช้งานไม่ได้ และทุกชั้นที่ต้องใช้สิทธิ์พิเศษล้มเหลวตามไปด้วย นี่คือข้อจำกัดด้านความสามารถ ไม่ใช่การบล็อกเวอร์ชัน แต่หน้า "ไม่พบแอป" เดิมบังโฟลเดอร์เดียวที่เปิดได้เสมอไว้
- **ไฟล์ที่เปิดได้เสมอ** — ปุ่ม **เลือกโฟลเดอร์…** เปิดตัวเลือกไฟล์ของระบบ โฟลเดอร์ที่เลือกจะถูกเก็บเป็น security-scoped bookmark และเปิดด้วยหน้าจัดการไฟล์ปกติ ไม่ต้องใช้ช่องโหว่ ไม่ต้องใช้ entitlement พิเศษ ไม่ต้องใช้ kernel offsets จึงเข้าไฟล์ได้จริงบน 27.0.1 ส่วนโฟลเดอร์ Documents ของ dekpop ก็เปิดได้เสมอ
- **ไม่มีทางตัน** — หน้าว่างตอนนี้มีปุ่ม **เปิด Documents ของ dekpop**, **เลือกโฟลเดอร์…** และ **ตรวจสอบความเข้ากันได้** ให้กดทันที
- **ตรวจสอบความเข้ากันได้** แสดงผลทีละชั้น (Documents ของแอป, อ่านคอนเทนเนอร์ตรง ๆ, MCM, ขอสิทธิ์ traversal, สแกน inode, ออกจากแซนด์บ็อกซ์) พร้อมรายละเอียดความล้มเหลว บันทึกลง log และกดคัดลอกรายงานไปส่งให้ช่วยแก้ได้
- เวอร์ชันปัจจุบัน `2.1.0` (build 21) อังกฤษ/ไทย 672 คีย์เท่ากันทุกประการ

> การเข้าคอนเทนเนอร์ของ **แอปอื่น** ยังต้องใช้ kernel offsets ที่ตรงกับเคอร์เนล ซึ่งยังไม่มีสำหรับ iOS 27.0.1 รายงานตรวจสอบจะบอกตรง ๆ ว่าชั้นไหนล้มเหลว แต่โฟลเดอร์ที่เลือกผ่าน Files และ Documents ของ dekpop ใช้งานได้เสมอ

## มีอะไรใหม่ใน 2.0.0 — เข้าถึงไฟล์ได้ทุก iOS (อัปเดตใหญ่)

> **iOS 27 ขึ้นไปตอนนี้เข้าและเปิดไฟล์ได้เหมือน iOS รุ่นเก่าทุกประการแล้ว**

- **แก้สาเหตุที่แท้จริง** — ยังมีการแยกโค้ดแบบ `majorVersion >= 26` ซ่อนอยู่ คือ iOS 26+ ถูกบังคับให้ใช้สิทธิ์ `bad_query` และถ้า sandbox escape ไม่สำเร็จจะถือว่าแอพล้มเหลวทันที บน iOS 27 ยังใช้ escape กับเคอร์เนลใหม่ไม่ได้ จึงไม่มีสิทธิ์เข้าถึง สแกน metadata ถูกข้าม และรายการแอปจาก LaunchServices หายไปจน Files ว่างเปล่า ส่วน iOS รุ่นเก่ายังอ่านไฟล์ได้ตรง ๆ จึงดูเหมือนมีปัญหาเฉพาะเวอร์ชันใหม่
- **ทุกเวอร์ชันใช้ชุดเดียวกันตามความสามารถจริง** — อ่านตรงด้วย `FileManager` → เปิดใช้งาน MCM → ขอสิทธิ์ `bad_query` → สแกน inode / อ่านพลิสต์ metadata ตรง ๆ ตรวจสอบความสามารถตอนรันจริง ไม่ดูเลขเวอร์ชัน iOS อีกต่อไป และชั้นใดล้มเหลวก็ยังไปชั้นถัดไปได้
- **sandbox escape เป็นเพียงส่วนเสริม** — `KernelExploit.run()` สำเร็จทันทีที่ได้ kernel R/W บนทุกเวอร์ชัน หาก escape ไม่สำเร็จ ระบบยังใช้ direct / MCM / grant / inode ต่อไป ไม่ปิดการใช้งาน Files
- **หน้าโฟลเดอร์มีทางสำรองแล้ว** — `listFiles(at:)` ใช้ inode walk เมื่อ `FileManager` อ่านไม่ได้ โฟลเดอร์จึงไม่โชว์ว่างบนเคอร์เนลใหม่ และการขอสิทธิ์ตอนนี้ตัดสินจากความสามารถจริง (ไม่ดูเวอร์ชัน) พร้อมลองใหม่ทุกครั้งที่โหลดรายการ
- **ชั้นเนทีฟรองรับเวอร์ชันอนาคต** — การค้นหา kernel base รับ Mach-O header ที่ตรวจแล้วตัวแรกบนทุกบิลด์ และจำกัดรอบการสแกน (ไม่วนค้างไม่รู้จบ) ส่วน CPU family ที่ไม่รู้จักบน iOS 26+ จะใช้ตาราง offsets ใหม่ล่าสุดแทนค่าพื้นฐาน iOS 17
- การ์ดด้านบนหน้า Files แสดงข้อความ **เข้าถึงไฟล์แบบสากล · ทุกเวอร์ชัน iOS** และประกาศตอนเปิดแอปแปลเป็นอังกฤษ/ไทยแล้ว
- เวอร์ชันปัจจุบัน `2.0.0` (build 20) โครงสร้าง IPA, bundle identifier และระบบ 2 ภาษาไม่เปลี่ยนแปลง

## มีอะไรใหม่ใน 1.5.0 — แท็บ แอป / ทางลัด / มอด

- **แท็บหมวดหมู่หน้าแรก** — แถบเลือกด้านบนสลับระหว่าง **แอป**, **ทางลัด** และ **มอด** เปิดแอปมาเจอสิ่งที่ต้องการทันที
- **ทางลัดโฟลเดอร์ที่เพิ่มและแก้ไขเองได้** — บันทึกโฟลเดอร์ใดก็ได้แล้วกระโดดเข้าไปทันที สร้างได้จากแท็บทางลัด หรือจากหน้า Files: กดค้างที่โฟลเดอร์แล้วเลือก **เพิ่มทางลัด** หรือใช้ **เพิ่มทางลัด** ในเมนู + สำหรับโฟลเดอร์ที่กำลังเปิดอยู่
- **คัดลอกที่อยู่ไฟล์** — กดค้างที่ไฟล์หรือโฟลเดอร์แล้วเลือก **คัดลอกพาธ** (หรือ **คัดลอกพาธโฟลเดอร์นี้** ในเมนู +) แล้วนำไปวางในช่องทางลัดด้วยปุ่ม **วาง** ตัวแก้ไขจะตรวจว่าพาธนั้นอยู่ในคอนเทนเนอร์แอปใด และเก็บเฉพาะส่วนที่สัมพันธ์กัน
- **ตัวแก้ไขทางลัด** — เลือกคอนเทนเนอร์แอปเป้าหมายหรือพื้นที่ทำงาน dekpop พิมพ์หรือวางพาธ (รองรับพาธเต็มที่ขึ้นต้นด้วย `/`) ดูตัวอย่างโฟลเดอร์ที่จะเปิดจริง และแจ้งเตือนเมื่อมีทางลัดของโฟลเดอร์เดิมอยู่แล้ว พร้อมแก้ไข เปิดในแท็บใหม่ คัดลอกพาธ หรือลบ
- **แท็บมอดสองเว็บ** — **KenModz** ([kenmodz.com](https://kenmodz.com/)) และ **Cheat iOS VIP** ([mods.cheatiosvip.net](https://mods.cheatiosvip.net/)) เปิดในเบราว์เซอร์ของแอปที่หน้าตาเข้ากับ dekpop รักษาคุกกี้และเซสชัน แสดงแถบโหลด พร้อมปุ่มย้อนกลับ / ไปข้างหน้า / หน้าแรก / โหลดใหม่ และ *เปิดใน Safari*
- **นำศูนย์ดาวน์โหลดออก** — หน้าต่างดาวน์โหลดแยกถูกนำออกแล้ว เซ็ตไฟล์ยังอยู่ที่ปุ่มรูปกล่องบน toolbar และใช้ขั้นตอนการใช้เซ็ต การเลือกปลายทาง และนโยบายไฟล์ซ้ำแบบเดิม
- **หน้าเปิดแอป + ประกาศ + ไอคอนใหม่** — เข้าแอปมาเจอหน้าโหลดไล่สีพร้อมแถบโหลดเคลื่อนไหว ตามด้วยการ์ดประกาศใส่รูปได้ที่แสดงทุกครั้งที่เข้าแอป และไอคอนแอพดีไซน์ใหม่ทั้งหมด
- ข้อมูลทั้งหมดเก็บในพื้นที่ทำงานของ dekpop (`AssetSets/`) จึงอยู่ต่อหลังอัปเดตแอปและเข้าถึงได้จาก Files
- เวอร์ชันปัจจุบัน `1.5.0` (build 14) โครงสร้าง IPA และ bundle identifier ไม่เปลี่ยนแปลง

## มีอะไรใหม่ใน 1.3.0 — อังกฤษ + ไทย

- **รองรับแค่ 2 ภาษา** คือ English (`en`) และ ไทย (`th`) เท่านั้น โดยลบไฟล์แปลภาษาเวียดนามและจีนตัวย่อออกจากโปรเจกต์และจาก bundle ที่ build แล้ว `CFBundleLocalizations` ตอนนี้คือ `(en, th)`
- **แปลภาษาไทยครบทุกคีย์** รวม 509 คีย์ใน `Localizable.strings` โดยคง `%@` / `%lld` ทุกตัวให้ตรงกับต้นฉบับ
- **สลับภาษาได้จากหน้าที่ใช้งานจริง** เนื่องจากแอปเหลือแค่ Files และหน้า Settings ไม่สามารถเข้าถึงได้แล้ว จึงเพิ่มเมนูรูปโลกใน toolbar ของหน้าหลักและทุกหน้าโฟลเดอร์ พร้อมตัวเลือกแบบแบ่งส่วน `English / ไทย` ด้านบนของรายการไฟล์ เปลี่ยนเมื่อไหร่ก็มีผลทันที
- **เลือกภาษาเริ่มต้นอัตโนมัติ** อุปกรณ์ที่ตั้งภาษาไทยจะเปิดด้วยภาษาไทย ส่วนอื่น ๆ เปิดด้วยภาษาอังกฤษ ค่าที่เคยบันทึกเป็น `vi` / `zh-Hans` จะถูกย้ายไปภาษาอังกฤษอัตโนมัติ
- เวอร์ชันปัจจุบัน `1.3.0` (build 9) โครงสร้าง IPA และ bundle identifier ไม่เปลี่ยนแปลง

> [!IMPORTANT]
> bundle identifier ยังคงเป็น `com.apple.mobile.MobileHouseArrest` โดยตั้งใจ เพราะ `mcm_bridge.m` ตรวจสอบค่านี้ก่อนเปิดใช้งานคอนเทนเนอร์แบบ MHA-C2 หากเปลี่ยนจะทำให้ฟีเจอร์ Files ใช้งานไม่ได้

## ธีม

มี 6 ธีมให้เลือก — **ม่วงป็อป**, **มิดไนต์**, **ซันเซ็ต**, **ซากุระ**, **ฟอเรสต์** และ **กราไฟต์** เปลี่ยนได้จากปุ่มจานสีบน toolbar (ทั้งหน้าแรกและในโฟลเดอร์) พร้อมการ์ดตัวอย่างสีจริง แตะแล้วทั้งแอปเปลี่ยนทันที ทั้งไอคอน ไล่สี การ์ด hero และหน้าเปิดแอป โดยระบบจำธีมที่เลือกไว้และยังปรับตามโหมดสว่าง/มืดให้เอง

## ฟีเจอร์

- **App Data Browser** — แปลง Container UUID ที่เปลี่ยนไปเรื่อย ๆ ให้เป็น app bundle identifier ที่เสถียร และเปิดพื้นที่ไฟล์แบบเนทีฟ
- **จัดการไฟล์** — ค้นหา, ดูตัวอย่าง, แชร์, นำเข้าหลายไฟล์, คัดลอก, ย้าย, วาง, เปลี่ยนชื่อ, ลบ, สร้างไฟล์/โฟลเดอร์, สร้าง ZIP และจัดการชื่อซ้ำอย่างปลอดภัย
- **หลายแท็บ** — แต่ละแท็บจำตำแหน่งโฟลเดอร์ของตัวเอง (บน iPad จะมีแถบแท็บ)
- **พื้นที่ทำงาน dekpop** — โฟลเดอร์ของคุณเองใน `On My iPhone` เข้าถึงได้จากหน้า Files
- **เซ็ตไฟล์** — รวมไฟล์ของคุณเองเป็นชุด เลือกหมวดหมู่และช่อง แล้วคัดลอกทั้งชุดไปยังแอปหรือโฟลเดอร์เป้าหมายได้ในคลิกเดียว
- **ทางลัดโฟลเดอร์** — บันทึกโฟลเดอร์ใดก็ได้แล้วเปิดได้ในแตะเดียว พร้อมคัดลอกพาธไฟล์มาวางในตัวแก้ไขทางลัดได้
- **เบราว์เซอร์มอด** — KenModz และ Cheat iOS VIP เปิดใน dekpop พร้อมปุ่มนำทางแบบเนทีฟ
- **ไม่ต้องเจลเบรก** — ไม่ติดตั้ง jailbreak แบบถาวร ไม่มี bootstrap หรือ daemon และไม่ฉีดโค้ดเข้าแอปอื่น
- **สองภาษา** — สลับระหว่าง English และ ไทยได้ทันทีจากไอคอนรูปโลกใน toolbar

## ความเข้ากันได้

รองรับทุกเวอร์ชัน iOS ที่ติดตั้งแอปได้ โดยไม่มีรายการเวอร์ชันหรือบิลด์ที่อนุญาต:

| รายการ | สถานะ |
| --- | --- |
| เวอร์ชันที่รองรับ | iOS ทุกเวอร์ชัน 16.0 ขึ้นไป (ทั่วไป, เบต้า และเวอร์ชันในอนาคต) |
| iOS 27.0.1 | ยอมรับชัดเจน — ไม่มีรายการที่อนุญาต ไม่มีเวอร์ชันสูงสุด |
| Build whitelist | ลบออกแล้ว |
| ไฟล์ที่เปิดได้เสมอ | Documents ของ dekpop + โฟลเดอร์ที่เลือกจากแอป Files (ใช้ได้แม้เข้าคอนเทนเนอร์ไม่ได้) |
| Deployment target | iOS 16.0 |
| กลไกเข้าถึงไฟล์ | Universal · direct / MCM / grant / inode — เหมือนกันทุกเวอร์ชัน iOS |
| แยกการเข้าถึงตามเวอร์ชัน | ลบออกใน 2.0.0 (ลบเงื่อนไข `>= 26`) |
| สำรอง offsets | baseline iOS 26.0 สำหรับ 26.1+ และเวอร์ชันอนาคต, baseline iOS 17.0 สำหรับต่ำกว่า 17.0, CPU family ที่ไม่รู้จักบน iOS 26+ ใช้ตารางรุ่นใหม่ล่าสุด |

> [!NOTE]
> ช่องโหว่เคอร์เนล (ส่วนเสริม) ยังต้องใช้ offsets ที่ตรงกับเคอร์เนลที่กำลังทำงาน หาก iOS เวอร์ชันนั้นไม่มีในตาราง offsets การรันอาจล้มเหลว โดยจะบันทึก `offsets: ... unverified` แล้วใช้ offsets ใหม่ล่าสุดแทนการหยุดทำงาน **แต่ Files ยังทำงานต่อผ่าน direct / MCM / grant / inode เสมอ** — ช่องโหว่ล้มเหลวไม่ปิดการเข้าถึงไฟล์บน iOS 27+ อีกต่อไป

## การเซ็นและติดตั้ง

- ฟีเจอร์ระดับอุปกรณ์ต้องเซ็นด้วย **ใบรับรอง enterprise** ที่คุณได้รับอนุญาตให้ใช้
- ไม่รองรับการติดตั้งผ่าน SideStore, AltStore, 3uTools หรือ LiveContainer
- Bundle identifier ต้องเป็น `com.apple.mobile.MobileHouseArrest` ห้ามเปลี่ยน
- โปรเจกต์นี้ไม่มีใบรับรอง โปรไฟล์ รหัสผ่าน หรือ IPA ที่เซ็นแล้ว CI จะสร้าง IPA **แบบยังไม่เซ็น** เท่านั้น

```bash
# 1. สร้าง IPA แบบยังไม่เซ็น (ต้องมี Xcode)
./scripts/build-unsigned-ipa.sh

# 2. เซ็นด้วยใบรับรอง enterprise ของคุณเอง
./scripts/resign-ipa.sh dekpop-unsigned.ipa "iPhone Distribution: Your Enterprise" /path/to/profile.mobileprovision dekpop-signed.ipa

# 3. ติดตั้งบนอุปกรณ์ที่ต่อผ่าน USB
./scripts/install-ipa.sh dekpop-signed.ipa
```

เป้าหมาย Xcode ยังชื่อ `3105` (`xcodebuild -target 3105`) แต่ `PRODUCT_NAME` คือ `dekpop` ดังนั้น bundle ที่ได้คือ `Payload/dekpop.app/`

## ไม่มี Mac ทำอย่างไร

ดู [docs/QUICKSTART.th.md](docs/QUICKSTART.th.md) สำหรับคำแนะนำแบบคลิกทีละขั้นตอน สรุปสั้น ๆ:

1. Push โปรเจกต์ขึ้น GitHub → **Actions > Build unsigned IPA** จะ build บน macOS runner ให้โดยไม่ต้องใช้ใบรับรอง
2. โหลด artifact `dekpop-unsigned-ipa` (หรือรัน `python scripts/download-unsigned-ipa.py`)
3. เซ็นด้วย ESign บนเครื่อง หรือ `scripts/resign-windows-zsign.ps1` บน Windows/Linux
4. ติดตั้งผ่าน ESign, enterprise OTA ผ่าน HTTPS, MDM หรือ Apple Configurator

> [!CAUTION]
> ใช้เฉพาะใบรับรอง enterprise ที่คุณได้รับอนุญาต อย่า commit ไฟล์ `.p12`, รหัสผ่าน หรือ `.mobileprovision` และอย่าวางคีย์ส่วนตัวในแชทหรือ issue
